PROPIEDADES DE LAS POTENCIAS

Potencias Básicas

Potencia de exponente cero

$a^0 = 1$

$6^0 = 1$

Potencia de exponente uno

$a^1 = a$

$6^1 = 6$

Signos en las Potencias

Exponente par

Las potencias de exponente par son siempre positivas.

$(-a)^n = a^n$

$2^6 = 64$

$(-2)^6 = 64$

Exponente impar

Las potencias de exponente impar tienen el mismo signo que la base.

$(-a)^n = -a^n$

$2^3 = 8$

$(-2)^3 = -8$

Operaciones con Potencias

Multiplicación con la misma base

$a^m \cdot a^n = a^{m+n}$

$7^5 \cdot 7^2 = 7^{5+2} = 7^7$

División con la misma base

$a^m : a^n = a^{m-n}$

$7^5 : 7^2 = 7^{5-2} = 7^3$

Potencia de una potencia

$(a^m)^n = a^{m \cdot n}$

$(7^5)^3 = 7^{5 \times 3} = 7^{15}$

Multiplicación con el mismo exponente

$a^n \cdot b^n = (a \cdot b)^n$

$2^3 \cdot 4^3 = (2 \cdot 4)^3 = 8^3$

División con el mismo exponente

$a^n : b^n = (a : b)^n$

$6^3 : 3^3 = (6 : 3)^3 = 2^3$

Exponentes Especiales

Exponente entero negativo

$a^{-n} = \frac{1}{a^n}$

$2^{-3} = \frac{1}{2^3} = \frac{1}{8}$

Exponente racional

$a^{\frac{m}{n}} = \sqrt[n]{a^m}$

$8^{\frac{2}{3}} = \sqrt[3]{8^2} = \sqrt[3]{64} = 4$

Exponente racional y negativo

$a^{-\frac{m}{n}} = \frac{1}{\sqrt[n]{a^m}}$

$4^{-\frac{3}{2}} = \frac{1}{\sqrt{4^3}} = \frac{1}{8}$
