# AGENTS.md

Static Astro 7 site (Spanish) for Ágora Academy. Content is data-driven JSON; pages are generated at build. Deploys to GitHub Pages on push to `main` via `.github/workflows/deploy.yml` (`site: https://agoraacademy.es`, served from `public/CNAME`).

## Commands

```bash
pnpm dev      # dev server at localhost:4321
pnpm build    # production build to ./dist/
pnpm preview  # preview production build
```

No lint, test, or typecheck scripts exist. Run `pnpm build` to validate changes and regenerate `.astro/types.d.ts`.

## Adding a theory topic

1. Create `src/content/topics/<slug>.json` (schema in `src/content.config.ts`; all content in Spanish).
2. Register it in `src/data/menu.ts` — pages only appear in nav if listed here.

`src/pages/theory/[slug].astro` auto-generates the page; no route code needed.

## Exercise PDFs

PDFs live in `public/ejercicios/<level>/<topic>/`, mapped in `src/data/exercises.ts`. Page is generated by `src/pages/exercises/[level].astro` from that mapping — a PDF without an entry in `exercisesData` is unreachable.

## Math graphs

`scripts/generate-math-graphs.py` (matplotlib + numpy, must be installed) renders images to `public/ejemplos/<folder>/`, referenced from topic JSON as `"/ejemplos/<folder>/file.png"`. Run from the project root. Full usage in `scripts/README.md`; use `draw_axes`, `save`, and the BLUE/RED/GREEN/ORANGE palette.

## Notes

- Math fields (`formula`, `example`) render via KaTeX; reference images inside JSON with an `<img>` tag (see `scripts/README.md`).
- Two content-data files, both required for a complete feature: `src/content/topics/*.json` (page) and `src/data/menu.ts` (nav) — plus `src/data/exercises.ts` for PDFs.
- Existing CLAUDE.md is largely accurate but names the PDF dir `public/exercises/`; the real dir is `public/ejercicios/`.
